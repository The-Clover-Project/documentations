### Curious about The Clover Project?
<p>The Clover Project is an AOSP-based custom ROM built for those who value speed, security, and reliability. If you're looking for a refined stock Android experience with subtle yet meaningful enhancements, this is for you.</p>

### Notes: 

```bash
 * This ROM is available with the Gapps build only.
 * Only official builds are eligible for OTA updates.
 * Android 15 is the latest OFFICIAL release.
```
